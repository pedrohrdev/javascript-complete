# JavaScript Complete

A comprehensive JavaScript learning repository covering fundamentals to advanced topics, including logic, object-oriented programming, and asynchronous programming.

## 📚 About

This repository contains a collection of JavaScript exercises and examples designed to build a solid foundation in JavaScript programming. Whether you're a beginner just starting your coding journey or an intermediate developer looking to sharpen your skills, you'll find valuable exercises and explanations here.

## 🎯 Topics Covered

- **JavaScript Fundamentals**
  - Variables and data types
  - Operators and expressions
  - Control flow (if/else, switch)
  - Loops (for, while, do-while)

- **Logic & Problem Solving**
  - Conditional logic
  - Algorithm basics
  - Code optimization
  - Debugging techniques

- **Object-Oriented Programming (OOP)**
  - Classes and objects
  - Constructors and prototypes
  - Inheritance and polymorphism
  - Encapsulation and abstraction

- **Asynchronous Programming**
  - Callbacks
  - Promises
  - Async/await
  - Error handling

## 100 Logic Exercises (NEW!)

Added **100 practical exercises** to train your logic:
- 🏁 **20 Basics**
- 👍 **20 Intermediate**
- 📦🔤 **20 Arrays and Strings**
- 🔧 **20 Objects and Functions**

**How to use:**
1. Open `exercicios/index.html` in your browser.
2. Open the Console (F12).
3. Click "Run" on the desired exercise.
4. Implement the logic in the `// TODO:` comments!
5. Solutions are commented - uncomment to verify.

Access the `exercicios/` folder to edit files directly.
